# 第 6 页：上传的临时文件夹

### 1. 上传临时文件夹的说明
* 客户端上传的文件首先存入 PHP 配置文件 `php.ini` 指定的临时文件夹中（如 `upload_tmp_dir = "B:/wamp64/tmp"`）。
* **生命周期**：当前请求脚本执行结束时，临时文件会被**系统自动清除**。

### 2. 上传文件对象的提取
* **推荐方式**：使用控制器基类属性 `$this->request->file('文件域名称')`；
* **助手函数方式**：`request()->file('文件域名称')`。

---

# 第 7 页：执行 Request 对象的 file 方法后

### 文件对象结构（`think\file\UploadedFile`）
通过 `$file = $this->request->file('fileName');` 获取到的对象包含以下属性：
* `originalName`：客户端上传的原文件名（如 `"04.jpg"`）
* `mimeType`：文件 MIME 类型
* `path`：临时文件存储路径（如 `"D:\wamp64\tmp"`）
* `realPath` / `pathname`：临时文件的实际全路径（如 `"D:\wamp64\tmp\phpB244.tmp"`）
* `size`：文件大小（字节）

### 业务使用规则
* **存储位置**：临时文件夹；
* 如果后续只需要解析内容而不需要持久存储，**直接使用临时文件即可**；
* 获取临时文件绝对路径：
  ```php
  $file = $this->request->file('scoreFile');
  $scoreFile = $file->getPathname();
  ```

# 第 11 页：核心方法介绍

### 表 8-1 组件核心方法介绍

| 层次 | 方法 | 作用 |
| :--- | :--- | :--- |
| **获取 Spreadsheet 对象** | `IOFactory::load($filePath)` | 加载 Excel 文件，返回 Spreadsheet 对象 |
| **获取 Worksheet 对象** | `$spreadsheet->getSheet(0)` | 获取第一个工作表（索引从 0 开始） |
| **转为数组** | `$worksheet->toArray()` | 将工作表内容转为二维数组 |

### 数组索引说明
`toArray()` 返回的二维数组，其列索引从 0 开始：
* 第 1 列（序号）：索引为 `0`
* 第 2 列（班级）：索引为 `1`
* 第 3 列（学号）：索引为 `2`
* 第 4 列（姓名）：索引为 `3`
* **第 5 列起（成绩项）**：索引从 `4` 开始（当提及“从第 4 列开始读取成绩”时，指的是数组索引 4）。

### 基础代码示例
```php
use PhpOffice\PhpSpreadsheet\IOFactory;

// 1. 加载 Excel 文件
$spreadsheet = IOFactory::load('/path/to/score.xlsx');

// 2. 获取第一个工作表
$sheet = $spreadsheet->getSheet(0);

// 3. 转为二维数组（每一行是一个子数组）
$data = $sheet->toArray();

// 4. 移除第一行表头
array_shift($data);
```

```php
/**
 * 设置成绩占比
 * @param int $taskId
 */
public function setWeight($taskId)
{
    try {
        // 比重参数（直接接收 JSON 格式的请求体）
        $json = file_get_contents('php://input');
        $params = json_decode($json, true);

        $result = (new ModelTask())->modelSetWeight($taskId, $params);
        if (!$result) {
            return $this->error(400, '教学任务总评比重重复设置', $result);
        }
        return $this->success(200, '教学任务总评比重设置成功', []);
    } catch (\Throwable $th) {
        $code = $th->getCode() > 200 ? $th->getCode() : 500;
        return $this->error($code, $th->getMessage());
    }
}
```

```php
/**
 * 设置总评比重
 * @param int $taskId
 * @param array $params
 * @return bool
 */
public function modelSetWeight($taskId, $params)
{
    try {
        // 1. 检查任务是否存在（防止传入无效 ID 导致假成功）
        $exists = Db::connect('edu_ru')->name('task')->where('ta_id', $taskId)->find();
        if (!$exists) {
            throw new \Exception('教学任务不存在，请刷新页面重试', 404);
        }

        // 2. 执行更新（无论影响行数是 1 还是 0，只要没报错就继续）
        Db::connect('edu_ru')->name('task')->where('ta_id', $taskId)->update($params);
        return true;
    } catch (\Throwable $th) {
        throw $th;
    }
}
```

# 第 28 页：控制器方法编写：`Score.php/importScoreFile`

```php
/**
 * 成绩录入（读取上传的成绩文件并返回待确认数据）
 * @param int $taskId 教学任务ID
 * @return string json字符串
 */
public function importScoreFile($taskId)
{
    try {
        // 步骤1：获取前端上传的 Excel 文件对象
        $file = $this->request->file('scoreFile');

        // 步骤2：读取文件绝对路径
        // 这里的绝对路径是服务器临时文件路径，无需手动移动文件即可交付 PhpSpreadsheet 解析
        $scoreFile = $file->getPathname();

        // 步骤3：调用模型层处理文件并获取组装后的成绩数据
        // 模型层内部负责进行验证、读取、合并已有记录等复杂数据逻辑
        $scores = (new ModelScore())->dealScoreFile($taskId, $scoreFile);

        // 步骤4：组装成功，返回统一格式的 JSON 响应
        return $this->success(200, '成绩文件读取成功', $scores);

    } catch (ValidateException $th) {
        // 步骤5：专门捕获业务校验异常（行级错误，如学号不属于本班、表内重复等）
        // 模型层抛出的是 JSON 字符串，这里重新反解析为数组返回给前端，方便逐条展示
        return $this->error(400, '成绩文件读取失败', json_decode($th->getMessage()));

    } catch (\Throwable $th) {
        // 步骤6：捕获其他所有异常（前置校验错误，如文件无学号、任务不存在、未设置权重等）
        // 如果异常没有附带有效 HTTP 状态码（如普通的错误），默认统一返回 500 服务器内部错误
        $code = $th->getCode() > 200 ? $th->getCode() : 500;

        // 返回统一的错误响应格式
        return $this->error($code, $th->getMessage());
    }
}
```

# 第 36 页：步骤一：读取文件内容，写入返回数组（基础框架）

```php
public function dealScoreFile($taskId, $scoreFile)
{
    // 1. 读取 Excel 并移除表头
    $scoreData = IOFactory::load($scoreFile)->getSheet(0)->toArray();
    array_shift($scoreData);

    // 2. 获取任务信息及权重配置
    $taskInfo = (new Task())->find($taskId);
    if (empty($taskInfo)) {
        throw new \Exception('教学任务编号错误', 404);
    }

    $overallCalculate = [];
```
