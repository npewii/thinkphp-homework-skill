# 第 7 页：配置参数赋值格式

### 其它配置格式支持
* 默认的配置文件都是 **PHP 数组方式**。
* 如果需要使用其它格式的配置文件，可以通过改变 `CONFIG_EXT` 环境变量的方式来更改配置类型。
* 在应用根目录的 `.env` 或者系统环境变量中设置：
  ```ini
  CONFIG_EXT=".ini"
  ```
* 支持的配置类型包括 `.ini`、`.xml`、`.json`、`.yaml` 和 `.php` 在内的格式支持。配置后全局或应用配置必须统一使用相同的配置类型。

### PHP 数组配置示例 (`app.php`)
```php
<?php
// 应用设置
return [
    // 应用地址
    'app_host'      => env('app.host', ''),
    // 应用的命名空间
    'app_namespace' => '',
    // 是否启用路由
    'with_route'    => true,
];
```

# 第 11 页：环境变量赋值

### 规范说明
* 可以在应用的根目录下定义一个特殊的 `.env` 环境变量文件，用于在开发过程中模拟环境变量配置（该文件建议在服务器部署的时候忽略）。`.env` 文件中的配置参数定义格式采用 `ini` 方式。例如：
  ```ini
  APP_DEBUG = true
  APP_TRACE = true
  ```
* 环境变量配置的参数会全部转换为大写；值为 `off`、`no` 和 `false` 等效于布尔值 `false`；值为 `yes`、`on` 和 `true` 等效于布尔值 `true`。

### 分组与数组建议
* 环境变量不支持普通数组参数，如果需要使用分组，可以使用：
  ```ini
  [DATABASE]
  USERNAME = root
  PASSWORD = 123456
  ```
  > **建议**：同一组用途的数据编为一个数组/分组。
* 如果要设置一个没有键值的数组参数，可以使用：
  ```ini
  PATHINFO_PATH[] = ORIG_PATH_INFO
  PATHINFO_PATH[] = REDIRECT_PATH_INFO
  PATHINFO_PATH[] = REDIRECT_URL
  ```

# 第 13 页：数据库配置文件 (`config/database.php`)

### 配置要点：
* `default` 配置用于设置默认使用的数据库连接配置。
* `connections` 配置具体的数据库连接信息，`default` 配置参数定义的连接配置必须存在。
* `type` 参数用于指定数据库类型。

### 配置方案示例：
```php
return [
    // 默认连接方案：mysql（如果不使用 connect 方法就是使用默认连接方案）
    'default'     => 'mysql',
    'connections' => [
        'mysql' => [
            // 数据库类型
            'type'     => 'mysql',
            // 服务器地址
            'hostname' => '127.0.0.1',
            // 数据库名
            'database' => 'thinkphp',
            // 数据库用户名
            'username' => 'root',
            // 数据库密码
            'password' => '',
            // 数据库连接端口
            'hostport' => '',
            // 数据库连接参数
            'params'   => [],
            // 数据库编码默认采用 utf8
            'charset'  => 'utf8',
            // 数据库表前缀
            'prefix'   => 'think_',
        ],
        // 备用的连接方案：demo
        'demo' => [
            'type'     => 'mysql',
            'hostname' => '127.0.0.1',
            'database' => 'demo',
            'username' => 'root',
            'password' => '',
            'hostport' => '',
            'params'   => [],
            'charset'  => 'utf8',
            'prefix'   => 'think_',
        ],
    ],
];
```

# 第 17 页：Db 类的引入

### ThinkORM 概述
* 数据库和模型操作采用独立的 **ThinkORM** 库，默认安装应用的时候会自动安装。
* **主要特性**：
  * 基于 PDO 和 PHP 强类型实现
  * 支持原生查询和查询构造器
  * 自动参数绑定和预查询
  * 简洁易用的查询功能
  * 强大灵活的模型用法
  * 支持预载入关联查询和延迟关联查询
  * 支持多数据库及动态切换
  * 支持 MongoDB
  * 支持分布式及事务
  * 支持断点重连
  * 支持 JSON 查询
  * 支持数据库日志
  * 支持 PSR-16 缓存及 PSR-3 日志规范
* **调用方式**：要使用 Db 类必须使用门面方式（`think\facade\Db`）调用。

### 查询构造器（Query Builder）
* 指的是 `Db::name()` 或 `Db::table()` 返回的对象。它提供了一套用 PHP 方法拼接 SQL 的 API，不用手写 SQL 字符串。
* 查询构造器就像一个「SQL 生成器」+「执行器」，负责把方法调用翻译成 SQL，然后执行并返回结果。
* 示例：
  ```php
  \think\facade\Db::connect('demo')
      ->table('user') // table方法返回查询构造器Query
      ->where('id', 10)
      ->find();
  ```

# 第 18 页：链式操作

* **语法模式**：`$obj->methodA()->methodB()->methodC();`
* **说明**：指一个对象的方法返回对象自身（或同类对象），从而可以连续调用。

### 实例 4 代码
```php
<?php
use think\facade\Db;

// 查询班级为 101 的学生，按学号降序，取前 10 条
$list = Db::name('stu')
    ->where('cl_id', '101')
    ->field('stu_id,stu_name,cl_id')
    ->order('stu_id', 'desc')
    ->limit(10)
    ->select();
```

### 表 4-1 常用的查询方法

| 方法 | 作用 | 示例 |
| :--- | :--- | :--- |
| `table()` | 指定表名（不含前缀） | `Db::table('stu')` |
| `name()` | 指定表名（自动加载前缀） | `Db::name('stu')` |
| `where()` | 条件查询 | `Db::name('stu')->where('cl_id', '101')` |
| `field()` | 指定查询字段 | `Db::name('stu')->field('stu_id,stu_name')` |
| `order()` | 排序 | `Db::name('stu')->order('stu_id', 'desc')` |
| `limit()` | 限制条数 | `Db::name('stu')->limit(10)` |
| `page()` | 分页 | `Db::name('stu')->page(1, 10)` |
| `find()` | 查询单条 | `Db::name('stu')->find(1)` |
| `select()` | 查询多条 | `Db::name('stu')->select()` |
| `value()` | 查询单列值 | `Db::name('stu')->value('stu_name')` |
| `column()` | 查询某列数组 | `Db::name('stu')->column('stu_name', 'stu_id')` |
| `count()` | 统计条数 | `Db::name('stu')->count()` |

# 第 20 页：查询数据

### 实例 5：查询数据
```php
// 查询单个数据使用 find 方法
// 最终生成的 SQL 语句是：SELECT * FROM `think_user` WHERE `id` = 1 LIMIT 1
Db::table('think_user')->where('id', 1)->find();

// 查询数据集使用 select 方法：
// 最终生成的 SQL 语句可能是：SELECT * FROM `think_user` WHERE `status` = 1
Db::table('think_user')->where('status', 1)->select();

// 值和列查询
// 返回某个字段的值
Db::table('think_user')->where('id', 1)->value('name');

// 查询某一列的值，返回数组
Db::table('think_user')->where('status', 1)->column('name');

// 指定 id 字段的值作为数组索引
Db::table('think_user')->where('status', 1)->column('name', 'id');
```

### 注意事项：
* `table` 方法必须指定完整的数据表名；
* `find` 方法查询结果不存在，返回 `null`，否则返回结果数组；
* `select` 方法查询结果是一个数据集对象，如果需要可用方法 `toArray` 转换为数组；
* `value` 方法查询结果不存在，返回 `null`；
* `column` 方法查询结果不存在，返回空数组。

# 第 21 页：插入数据

### 实例 6：插入数据
```php
<?php
// 插入单条并获取自增主键ID
$id = Db::name('stu')->insertGetId([
    'stu_id'   => '2021001',
    'stu_name' => '张三',
    'cl_id'    => '101',
]);

// 插入多条
Db::name('stu')->insertAll([
    ['stu_id' => '2021002', 'stu_name' => '李四', 'cl_id' => '101'],
    ['stu_id' => '2021003', 'stu_name' => '王五', 'cl_id' => '102'],
]);
```

### 注意事项：
* `insert` 方法添加数据成功返回添加成功的条数，通常情况返回 1；
* `insertAll` 方法添加数据成功返回添加成功的条数；
* 默认情况下插入的字段不存在，就会抛出异常。

# 第 22 页：更新数据

### 实例 7：更新数据
```php
<?php
// 更新单条
Db::name('stu')
    ->where('stu_id', '2021001')
    ->update(['stu_name' => '张三丰']);

// 批量更新
Db::name('stu')
    ->where('cl_id', '101')
    ->update(['status' => 1]);

// 字段自增
Db::name('stu')
    ->where('stu_id', '2021001')
    ->inc('score', 10)
    ->update();
```

### 注意事项：
* `update` 方法返回影响数据的条数，**没修改任何数据返回 0**。

# 第 23 页：删除数据

### 实例 8：删除数据
```php
<?php
// 删除单条
Db::name('stu')->where('stu_id', '2021001')->delete();

// 批量删除
Db::name('stu')->where('cl_id', '101')->delete();

// 删除所有
Db::name('stu')->delete(true);
```

### 注意事项：
* `delete` 方法返回影响数据的条数，没有删除返回 0；
* 如果不带任何条件调用 `delete` 方法会提示错误，如果确实需要删除所有数据，要使用 `delete(true)`；
* 一般情况下，业务数据不建议真实删除数据，系统提供了软删除机制。
