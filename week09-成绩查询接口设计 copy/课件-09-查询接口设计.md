# 第 10 页：模型方法设计：Task.php/getTaskScore（架构要点）

1. **多级关联预载入**：使用 `with(['teInfo', 'classInfo.stus', 'scores', 'courseInfo'])`。注意这里包含了嵌套关联 `classInfo.stus`（先查班级，再查班级下的所有学生），以及独立的成绩关联 `scores`。这能一次性把页面需要的所有数据查出来，极大减少数据库连接次数。
2. **任务信息组装与空值容错**：在组装 `$task` 数组时，由于使用了多表关联，为了防止因为脏数据（如某门课的教师被删除了）导致系统抛出致命错误，使用空安全运算符 `?->` 并搭配 `??` 提供默认值（如“未知教师”）。
3. **核心性能优化（空间换时间）**：
   * **痛点**：如果在遍历学生时，每次都用 `foreach` 去遍历成绩集合寻找匹配项，时间复杂度将是平方级的 $O(N^2)$。如果班级有 50 人，就要比对 2500 次。
   * **解法**：我们先遍历成绩集合，以学号（`sc_stu`）为键，构建一个字典数组 `$scoresDict`。PHP 底层的数组是哈希表实现，查找时间复杂度为 $O(1)$。这样在后续遍历学生找成绩时，只需 `$scoresDict[$stu->stu_id]` 即可瞬间取出，将时间复杂度降至线性的 $O(N)$。
4. **嵌套数据遍历与数据兜底**：
   * 使用 `if ($taskRe->classInfo && $taskRe->classInfo->stus)` 进行防御性判断，防止班级下没有任何学生时引发遍历报错；
   * 遍历学生时，通过 `?? null` 兜底。如果该学生在字典中找不到成绩（即还没录入），则 `$stuScore` 为 `null`，后续的成绩字段也会自动输出为 `null`，保证前端表格不会错位或报错。

# 第 11 页：模型代码实现：Task.php/getTaskScore（前半部分）

```php
/**
 * 获取教学任务的成绩
 * @param int $taskId 教学任务ID
 * @return array 成绩列表
 */
public function getTaskScore($taskId)
{
    // 步骤1：使用 with 预载入关联查询
    // 一次性加载：教师信息(teInfo)、班级信息及其学生(classInfo.stus)、成绩记录(scores)、课程信息(courseInfo)
    // 避免 N+1 查询问题，提升查询性能
    $taskRe = $this->with(['teInfo', 'classInfo.stus', 'scores', 'courseInfo'])
        ->where('ta_id', $taskId)->find();

    // 步骤2：判断教学任务是否存在
    // find() 查询不到时返回 null，若不存在则抛出 404 异常
    if (!$taskRe) {
        throw new \Exception('教学任务编号错误', 404);
    }

    // 步骤3：组装任务基本信息
    // 使用 ?-> 空安全运算符，防止关联数据（教师、班级、课程）被删除时导致空指针报错
    // 若关联数据为 null，则使用 ?? 提供默认值兜底
    $task = [
        'ta_id'     => $taskId,
        'ta_te'     => $taskRe->teInfo?->te_name ?? '未知教师',
        'ta_class'  => $taskRe->classInfo?->cl_name ?? '未知班级',
        'ta_c_name' => $taskRe->courseInfo?->c_name ?? '未知课程',
        'ta_c_type' => $taskRe->courseInfo?->c_type ?? '未知考试类型',
        'ta_c_exam' => $taskRe->courseInfo?->c_exam ?? '未知考试方式'
    ];
```

# 第 12 页：模型代码实现：Task.php/getTaskScore（后半部分）

> **关键易错点提示**：
> 1. 构建字典时取的是**成绩模型**的学号字段 `sc_stu`，而不是学生模型的字段 `stu_id`；
> 2. `foreach` 外层遍历的是**学生模型对象集合**，因此学生 ID 使用 `$stu->stu_id`；
> 3. 从哈希字典匹配出**成绩模型对象**后，再使用成绩模型的字段取出各项成绩。

```php
    // 步骤4：将成绩结果转化为以学号为键的字典数组
    // 目的：后续遍历学生列表时，可通过学号 O(1) 快速匹配成绩，避免嵌套循环
    $scoresDict = [];
    if ($taskRe->scores) {
        foreach ($taskRe->scores as $score) {
            $scoresDict[$score->sc_stu] = $score;
        }
    }

    // 步骤5：遍历班级学生，组装成绩列表
    // 以班级学生为基准，确保未录入成绩的学生也能出现在列表中（成绩字段为 null）
    $scores = [];
    if ($taskRe->classInfo && $taskRe->classInfo->stus) {
        foreach ($taskRe->classInfo->stus as $stu) {
            // 从字典中按学号取出成绩，没有录入成绩的为 null
            $stuScore = $scoresDict[$stu->stu_id] ?? null;

            $scores[] = [
                'sc_stu_id'   => $stu->stu_id,
                'sc_stu_name' => $stu->stu_name,
                // 使用 ?-> 防止成绩不存在时报错，未录入的字段为 null
                'sc_normal'   => $stuScore?->sc_normal,
                'sc_lab'      => $stuScore?->sc_lab,
                'sc_midterm'  => $stuScore?->sc_midterm,
                'sc_final'    => $stuScore?->sc_final,
                'sc_overall'  => $stuScore?->sc_overall,
                'sc_makeup'   => $stuScore?->sc_makeup,
                'sc_again'    => $stuScore?->sc_again
            ];
        }
    }

    // 步骤6：返回任务基本信息和成绩列表
    return ['task' => $task, 'score' => $scores];
}
```

# 第 21 页：控制器方法完整代码：Score.php/getStuScore

```php
/**
 * 显示学生的成绩单
 * @return string json字符串
 */
public function getStuScore()
{
    try {
        // 步骤1：从 JWT 认证信息中获取当前登录学生的学号 (stu_id)
        // jwtUser 是 JWT 中间件解析后注入到 request 对象中的用户信息
        $stuId = $this->request->jwtUser['uid'];

        // 步骤2：获取分页条数 limit
        // 从 GET 参数中读取 limit，默认为 15 条/页，并强制转换为整型，防止非法字符串
        $limit = (int)$this->request->get('limit', 15);

        // 步骤3：从请求中获取查询参数
        // 使用 only() 方法白名单接收，只取 taskId、startTerm、endTerm 三个参数
        // 如果请求中没有传这些参数，则使用默认值 0
        $params = $this->request->only(['taskId' => 0, 'startTerm' => 0, 'endTerm' => 0]);

        // 步骤4：调用模型层方法执行成绩查询
        // 传入学生学号、查询参数、分页条数，返回分页结果数组
        $score = (new ModelScore())->getScore($stuId, $params, $limit);

        // 步骤5：判断查询结果是否为空
        // 如果总记录数为 0，返回提示信息（仍然返回 200 状态码，属于正常查询结果）
        if ($score['total'] == 0) {
            return $this->success(200, '查询成功，但暂无成绩', $score);
        }

        // 步骤6：查询结果非空，返回成功响应和成绩数据
        return $this->success(200, '成绩获取成功', $score);

    } catch (\Throwable $th) {
        // 步骤7：异常处理
        // 如果异常没有设置错误码，则默认使用 500（服务器内部错误）
        $code = $th->getCode() ?: 500;

        // 返回错误响应，包含错误码和异常信息
        return $this->error($code, $th->getMessage());
    }
}
```

# 第 22 页：模型方法设计：Score.php/getScore（关联与条件）

> **注意**：`hasWhere` 方法在 ThinkPHP 8 中，如果用在闭包中，是针对**关联模型**进行查询条件限制。

```php
/**
 * 获取学生的某些成绩
 * @param int $stuId 学号
 * @param array $params ['taskId', 'startTerm', 'endTerm']
 * @param int $limit
 * @return array 成绩列表
 */
public function getScore($stuId, $params, $limit = 15)
{
    // 1. 构建基础查询链：深度预载入成绩关联的任务、课程、教师、学生信息
    $scores = $this->with(['taskInfo.courseInfo', 'taskInfo.teInfo', 'stuInfo']);

    // 2. 学年学期区间判定
    if ($params['startTerm'] == 0 && $params['endTerm'] == 0) {
        // 2.1 未传区间，获取当前学期并利用 hasWhere 穿透到任务表过滤
        $params['startTerm'] = TermTool::thisTerm();
        $scores = $scores->hasWhere('taskInfo', ['ta_term' => $params['startTerm']]);
    } else {
        // 2.2 传入区间，利用闭包穿透查询学期范围
        $scores = $scores->hasWhere('taskInfo', function ($query) use ($params) {
            $query->where('ta_term', 'between', [$params['startTerm'], $params['endTerm']]);
        });
    }

    // 3. 按特定教学任务精确过滤（如果前端有传 taskId）
    if (array_key_exists('taskId', $params) && $params['taskId'] != 0) {
        $scores = $scores->where('sc_task', $params['taskId']);
    }

    // 4. 组装分页附加参数（关键）：将 stuId 合并入参数数组，确保前端翻页时不会丢失学号参数
    $queryParams = array_merge($params, ['stuId' => $stuId]);
```

```php
            'te_name'     => $value->taskInfo?->teInfo?->te_name ?? '未知教师',

            'sc_lab'      => $value->sc_lab,
            'sc_midterm'  => $value->sc_midterm,
            'sc_final'    => $value->sc_final,
            'sc_overall'  => $value->sc_overall,
            'sc_makeup'   => $value->sc_makeup,
            'sc_again'    => $value->sc_again
        ];
    }

    // 步骤8：返回分页结果
    return $stuScore;
}
```
